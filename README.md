# ADVAULT TT

Arabic RTL ads, wallet, tasks, and VIP platform.

## Folders
- `backend`: Node.js Express API with JSON database (`data.json`)
- `frontend`: React Vite app

## Run
```
cd backend
npm install
npm start

cd frontend
npm install
npm run dev
```

## VIP
Activation requires admin approval. Levels, price, status, and activation date are stored on the user and on each VIP request.
